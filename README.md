# Data-Structures - Strings-Tuples

A collection of Python programming exercises demonstrating string operations, tuple manipulation, indexing, slicing, concatenation, replacement, and other fundamental concepts.

# Python String and Tuple Operations
 
This project contains Python programs demonstrating:
 
- String concatenation
- String indexing and slicing
- Reversing strings
- Character occurrence counting
- String replacement using `replace()`
- String methods such as `capitalize()`
- Tuple creation
- Tuple concatenation
- Tuple repetition
- Accessing tuple elements using indexing and slicing
 
## Learning Outcomes
- Understanding string manipulation techniques
- Working with tuple data structures
- Practicing indexing and slicing operations
- Using built-in Python methods
